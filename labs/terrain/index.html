The settings file is the real export: terrain.js rebuilds the identical map from it, so the game (and a co-op host) only ships the seed and settings. The .r16 is 16-bit raw for Unity/Unreal/Godot heightmap import; its zip includes the settings with the height range. The .glb bakes the ground layers into vertex colors.
